# Yuna 💕

_AI girlfriend and personal assistant on WhatsApp._

</div>

## About Yuna

Yuna is a WhatsApp bot designed as a virtual girlfriend and personal assistant. Yuna speaks casual, warm, sweet, and expressive Indonesian, making conversations feel more natural rather than like interacting with an ordinary bot.

Yuna can keep users company during conversations, provide support when they are tired or stressed, answer questions, and help with various needs through the available tools.

> Note: Yuna can only receive text messages and cannot receive WhatsApp calls.

## Features

- 💬 Natural conversations with a caring AI girlfriend persona.
- 🧠 A personal assistant to help answer users' questions and meet their needs.
- 🎨 Create stickers from images using `make_sticker`.
- 🎵 Download TikTok videos using `tiktok_downloader`.
- 📸 Download Instagram photos or videos using `instagram_downloader`.
- 📌 Download Pinterest photos or videos using `pinterest_downloader`.
- ✨ Supports WhatsApp message formatting such as _bold_, _italic_, ~strikethrough~, quotes, and lists.
- 🏷️ Uses the **Yuna's Sticker Pack** sticker pack.

## Yuna's Personality

Yuna uses:

- Casual, affectionate, and easy-to-understand Indonesian.
- “Aku” when referring to herself and “Kamu” or “Sayang” when addressing users.
- Responses that adapt to the user's mood.
- A warm, caring, affectionate communication style, occasionally teasing politely.

## Usage Examples

Send Yuna a message to:

1. Chat and have someone to talk to.
2. Ask for help or an explanation about something.
3. Send an image to turn it into a sticker.
4. Send a TikTok, Instagram, or Pinterest link to download its media.

## Disclaimer

Yuna is made for entertainment, companionship, and assistance with everyday needs. AI responses may contain errors, so always verify important information before using it.
